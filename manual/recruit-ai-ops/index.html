1はじめに

Recruit AI Opsは、人材紹介会社のスカウト運用を回すための基盤です。評価ルールを作り、候補者を判定し、スカウト文面をつくり、面接・オファーを経て、数字で振り返るまでを7つの機能でつなぎます。

運用フローの段階使う機能このマニュアルの節
基準をつくる評価ルールの自動生成3-1
候補者を判定するA/B/C判定の基準3-2
スカウト文面をつくるスカウトの型3-3
面接に臨む面接準備AI／面接実行AI3-4
数字で振り返る採用ダッシュボード3-5
オファーを出すオファーレターAI3-6

押さえておきたい前提：人が最終確認する

AIが出すのは、あくまで下書きと判定の補助です。評価ルールは人が「確定」するまで判定に使われず、スカウトも候補者ごとに人が内容を確認してから送信します。AIの判定結果も補助であり、最終判断は人が行います。

2使い始める

Freeプランの始め方

  1. 登録画面を開く「無料で始める」から Recruit AI Opsのサイト を開き、新規アカウントの作成画面に進みます。
  2. メールアドレスとパスワードを設定する利用規約とプライバシーポリシーへの同意が必要です。クレジットカードは不要です。
  3. 確認メールのリンクを開く届いた確認メールのリンクを開くと登録が完了します。リンクを開く前はログインできません。
  4. ログインする初回は、サイドメニューに はじめに が表示され、セットアップの手順（下記）を案内します。

Freeプランは求人1件・1席です。A/B/C判定の基準やスカウト文の型など、基本機能をお試しいただけます。

Chrome拡張機能のセットアップ

スカウト文面を媒体の画面で生成する場合は、Chrome拡張機能を使います。はじめに の画面に、次の3ステップが表示されます。

  1. Chrome拡張機能をインストール：Chrome ウェブストアから Recruit AI Ops 拡張機能を追加します。
  2. 拡張機能から自動ログイン：ブラウザ右上の Recruit AI Ops アイコンをクリックすると、ログイン中のアカウントで連携されます。連携を確認できると、画面の状態が自動で「完了」に変わります（数秒かかる場合があります）。
  3. 候補者ページで使ってみる：LinkedIn や Wantedly などの候補者ページを開き、拡張機能アイコンをクリックして文面を生成します。

管理画面の右上には、拡張機能の連携状況（「拡張機能 連携中」／「拡張機能 未検出」）が表示されます。

AIの使い分け：手元のClaude / ChatGPTと、お試し生成

Recruit AI Opsでは、AIの動かし方が2通りあります。

手元のClaude / ChatGPTサーバー側のお試し生成
前提利用者ご自身が契約しているClaudeまたはChatGPTAIの契約がなくても使える
回数A/B/C判定とスカウト文面は、回数の上限なく使えるアカウントごとに20回まで。20回で止まり、プランを上げても増えない
対象「型」と判定基準を手元のAIに渡して実行書類選考の実行、面接準備AI、面接実行AI、オファーレターAI、評価ルールの下書き生成、Chrome拡張の文面生成

Claudeにつなぐ

サイドメニューの 設定 にある Claudeにつなぐ から接続します。通常は、案内された URL を Claude のカスタムコネクタに貼り、ログインして許可するだけです。

  1. Claude のカスタムコネクタに、画面に表示された URL を貼ります。
  2. ログイン画面が開いたら、Recruit AI Ops にログインします。
  3. 組織名と許可する内容を確認して、許可します。

接続後は「この求人でB以上だけ出して」のように、言葉で絞り込みや記録を頼めます。接続はいつでも失効できます。組織によっては、接続できるのがオーナー（管理者）だけに限られている場合があります。

ChatGPTなど、手元のAIでコピー＆ペーストして使う

Claudeに接続せずに使う場合は、サイドメニュー 設定 の 手元のAIで実行（コピペ） を使います。

  1. 材料を選んでパッケージを作る：機能、求人、候補者、種類を選び、パッケージを作る を押します。
  2. 手元のAIに貼って実行する：コピー（または ダウンロード）したパッケージを、お使いのAIに貼り付けます。
  3. 結果を取り込む：AIが返した結果（JSON）を貼り付けて 検証して保存 を押します。

取り込みに失敗した場合は、エラー内容を表示します。そのエラーをAIに伝えて直してもらい、同じ task_id で貼り直してください。この方法は、サーバー側のお試し回数を消費しません。

3機能ごとの使い方

運用フローの順に説明します。画面名は、管理画面のサイドメニューに表示される名称です。

3-1. 評価ルールの自動生成

過去の選考結果をもとに、AIが評価基準の下書きを作ります。サイドメニューの 書類選考 の並びにある AI選考基準の下書き から使います。

  1. 選考結果を記録しておく下書きの材料は、求人ごとの過去の選考結果（通過・見送り）です。結果は 結果と知見 の画面などから記録します。
  2. 求人を選んで下書きを作るAI選考基準の下書き で求人を選び、下書きを作成 を押します。
  3. 内容を確認・修正する下書きを開くと、観点（重要度つき）、Must（必須）・Want（歓迎）・NG（避けたい）、A・B・Cそれぞれの目安が表示されます。直したいところを修正し、修正を保存 を押します。AI原案との差分も確認できます。
  4. 「確定」するこの内容で確定する を押し、確認ダイアログで進めると確定します。確定した基準は、書類選考の 選考基準テンプレート から選べるようになります。
  • 確定するまで判定には使われません。下書きの状態では、書類選考で使われません。確定後は、画面上で編集できなくなります。
  • 辞退したケースは材料に使いません。画面には「前進」「見送り」「辞退（除外）」の件数が、生成の根拠として表示されます。
  • サンプルが不足していると、下書きは作られません。評価サンプル（前進と、企業側の見送りの合計）が最低4件ない求人では、生成されずにその旨が表示されます。
  • 警告は隠さず表示されます。警告がある場合は、該当項目を修正・削除するか、内容を確認したうえで、確定時にチェックを入れます。
  • サンプルは匿名化してAIに渡されます。

評価ルールの下書きは、手元のAIで作ることもできます（前述の 手元のAIで実行（コピペ） に、評価ルールの下書きの項目があります）。

3-2. A/B/C判定の基準

確定した基準と求人のMust / Want / NGが物差しになり、候補者を同じ基準でA/B/Cに分けます。

判定意味運用の目安
A送付推奨内容を確認して、スカウトに進めます
B人の確認Mustの不明点や希望条件を、人が見て判断します
C送付非推奨Must未達か、実務適性が明確に不足している場合です

Must未達はC、判断材料が不明ならBになります。業界の近さだけでは、グレードは変わりません。

書類選考画面での使い方

サイドメニュー 書類選考 を使います。

  1. 候補者のCV・職務経歴書のテキストと、求人票（JD）のテキストを貼り付けます。求人管理 に保存した求人テンプレートから選ぶこともできます。
  2. 必要に応じて 選考基準（任意） を入力するか、選考基準テンプレート から確定済みの基準を選びます。
  3. 使用するAIモデルを選び、選考を実行する を押します。
  4. 結果に、合否、マッチスコア、レビューシート（A/B/Cの根拠）、評価コメント、マッチしている点、懸念点が表示されます。

過去の結果は 選考履歴 で見られます。レビューシートは求人ごとに残せ、チームで共有できます（チームでの共有はProプラン（3席）から。詳しくは製品紹介ページのFAQをご覧ください）。

この画面の「選考を実行する」は、サーバー側のAI（お試し生成）で動きます。回数に上限のない手元のClaude / ChatGPTで判定する場合は、前述の Claudeにつなぐ または 手元のAIで実行（コピペ） を使います。

3-3. スカウトの型

スカウトの完成文は、「固定部分」と「AIが書く部分」の分担でできています。

固定部分（AIは触れない）AIが書く部分
宛名の敬称、結びの固定文 冒頭1文、本文。あわせて、求人から読み取れる「見落とされがちな強み」の候補を3つ挙げ、確認用に示します（強みは本文を通して文面に反映されます）

固定部分を揃え、AIが書く部分を短くすることで、文面の品質をそろえやすくなります。

型の登録

サイドメニューの スカウト生成 の区分にある次の画面で、文面生成の材料を整えます。

  • 求人管理：拡張機能で使う求人（求人テンプレート）を登録します。タイトル、求人情報のほか、想定年齢・想定年収も任意で入力できます。
  • スカウト文プロンプト：Chrome拡張のスカウト文生成で使うプロンプトを登録します。タイトルと内容を入力して 保存 します。書き方に迷ったときは、画面下の参考ライブラリから、空き枠に取り込めます（既存の入力は上書きされません）。

登録できる件数は、プランによって上限があります。

媒体の画面で使う

候補者ページを開いた状態で、Chrome拡張機能のアイコンをクリックすると、型と候補者情報を横に置いて確認しながら、スカウト文面を生成できます。LinkedIn や Wantedly などの候補者ページで使えます。

スカウトは自動では送信されません。文面はAIが下書きし、送信は候補者ごとに、人が内容と事実を確認してから行います。

3-4. 面接準備AI／面接実行AI

面接準備AI

サイドメニュー 面接準備 から使います。面接前準備 と 面接後評価 の2つのモードがあります。

モード入力用意されるもの
面接前準備 候補者情報（CV・レジュメなどのテキスト） BIG5・DISC・モチベーション診断、性格・適性サマリー、見極めポイント、想定質問リスト（各質問に「見る点」つき）
面接後評価 候補者情報と、面接テキスト（文字起こし・面接メモ） 詳細な分析と合否判定（100点満点）、強み・懸念点、評価理由、魅力付けポイント、フィードバックコメント例

求人テンプレート（任意）や評価基準（任意）を選ぶと、補足としてAIに渡されます。性格特性の分析は参考情報です。最終的な採用判断は、面接や実務の評価を通じて人が行います。

面接実行AI

サイドメニュー 面接実行AI から使います。面接中の会話を文字起こしし、AIがアドバイスを返し、終了後に評価レポートを作ります。

  1. 面接を開始する+ 新しい面接を開始 から、候補者名とポジション名などを入力して面接セッションを作ります。
  2. 面接を録る面接の画面で録音を開始すると、発話が文字起こしされます。ブラウザの音声認識を使うため、Google Chrome または Microsoft Edge を使い、マイクの利用を許可してください。面接準備AIの結果を連携している場合は、想定質問が画面に表示されます。
  3. アドバイスを求める面接中に アドバイスを求める を押すと、直近の会話を踏まえたAIアドバイスが表示されます。
  4. 面接を終了して評価へ面接終了 → 評価へ から評価レポートを生成します。

評価レポートには、総合スコア、推薦判定（A: 強く推薦／B: 要検討／C: 推薦せず）、候補者サマリー、評価項目、ポジティブな発言、懸念点、次のアクションなどが含まれます。推薦判定が出た候補者は、そのままオファーレターの作成に進めます。

3-5. 採用ダッシュボード

スカウトやATSのCSVを取り込んで、選考のどこで人が落ちているかを可視化します。サイドメニューの 採用分析 の区分にある 採用ダッシュボード を使います。画面には ダッシュボード と データ管理 の2つのタブがあります。

CSVを取り込む

  1. CSVをアップロードするデータ管理 タブで、CSVファイルをドラッグ＆ドロップするか、ボタンから選択します。最大10MBで、文字コード（Shift_JIS／UTF-8）は自動判定されます。
  2. 列を対応づける列マッピングの画面で、ステータス列（必須）、応募日列、求人名列、媒体列、応募者ID列を選びます。ラベル（例：媒体名と月）も付けられます。
  3. ステータス値を段階に対応づけるステータス列の値を、下記の8段階のいずれかに紐づけます。未選択の値はスキップされます。
  4. 保存する保存 を押したときに、はじめて取り込まれます。

手元にCSVがない場合は、サンプルデータで試す や サンプルCSVをダウンロード で試せます。

8段階のファネル

スカウト送信 → 返信 → カジュアル面談 → 一次面接 → 二次面接 → 最終面接 → 内定 → 入社

ダッシュボード タブには、全体の歩留まり率（送信→入社）、段階ごとの件数・送信からの移行率・前段階からの離脱率、月次推移が表示されます。媒体、求人名、アップロード単位で絞り込めます。月次推移には応募日が必要です。

要対応と週次の数字

サイドメニュー先頭の ダッシュボード（ホーム画面）には、運用の状況をつかむための情報が並びます。

  • 要対応：今日見る候補（返信があり、次の段階が未記録の候補）と、付け直しが多い求人（基準の見直し候補）が並びます。
  • 今週の数字：月曜はじまり・日本時間で、週ごとの数字を確認できます。
  • フィードバックの見える化：週ごとの返信率と付け直し率、求人別の集計を表示します。入力済みの記録から集計しており、AIの再学習はしていません。

返信や結果の記録は 結果と知見 の画面から入力します。Claudeからも同じ記録を参照できます。

3-6. オファーレターAI

サイドメニューの オファー の区分にある オファーレター作成 から使います。候補者の動機タイプに合わせた魅力付けを織り込んだ文面を作ります。

モードつくれるもの
正式オファーレター候補者に送る、オファーの文面
面談スクリプトオファー面談で話す内容の台本
フォローメールオファー後の追いメール
  1. 候補者の情報を入れる候補者氏名と、経歴・志向を入力します。面接実行AIの評価レポートから このまま候補者にオファーレターを作成 で進むと、候補者情報と動機データが自動で引き継がれます。
  2. オファー条件を入れる提示年収、役職、入社日、勤務地、雇用形態を入力します。未入力の項目は、AIが「（要確認）」と明示します。
  3. 自社の魅力・カルチャーを入れる事業の強み、働き方、成長機会、カルチャーなど、候補者に伝える材料を入力します。よく使う内容は オファーテンプレート に保存して選べます。
  4. 文面の種類・トーン・AIモデルを選んで生成する生成後は、文面、主な魅力付けポイント、推奨フォローアクションが表示され、文面をコピーできます。

面接準備AIの動機診断データがある候補者では、動機タイプに合わせた訴求が強化されます。データがない場合は、汎用の魅力付けで生成されます。

生成した文面は、送る前に必ず人が内容と事実を確認してください。

4よくある質問

製品全体のご質問は製品紹介ページのFAQをご覧ください。ここでは使い方に関するものを取り上げます。

Claude / ChatGPTの契約は別途必要ですか？

A/B/C判定とスカウト文面づくりは、利用者が契約しているClaudeまたはChatGPT（手元のサブスク）で行う設計で、この2つにAlumNET側のAPI費用はかかりません。AIの契約がない場合は、サーバー側のお試し生成（20回）で使い心地を確認できます。

サーバー側の「お試し生成20回」を使い切ったらどうなりますか？

アカウントごとに20回で止まり、プランを上げても増えることはありません。一方、A/B/C判定とスカウト文面は、手元のClaude / ChatGPTに「型」と判定基準を渡す形で、回数の上限なく使えます。対象の機能は、2. 使い始めるの表をご覧ください。

評価ルールの下書きは、そのまま判定に使われますか？

使われません。下書きは、人が内容を確認・修正して「確定」するまで、判定には使われません。サンプルが不足している求人では下書き自体が作られず、辞退したケースは基準づくりの材料に使いません。

スカウトは自動で送信されますか？

されません。文面はAIが下書きしますが、送信は候補者ごとに人が内容を確認してから行うHuman in the Loopの設計です。AIの判定結果もあくまで補助であり、最終判断は人が行います。

A/B/C判定の基準とスカウトの型は、別々に使えますか？

はい、独立して使えます。A/B/C判定の基準だけ、スカウトの型だけ、オファーレターだけを使うこともできます。A判定（送付推奨）が出た候補者のスカウトへの引き継ぎや、面接で推薦判定が出た候補者のオファーレターへの引き継ぎもできます。いずれも送信は人が確認して行います。

採用ダッシュボードのCSVは、どんな形式でも取り込めますか？

最大10MBのCSVを取り込めます。文字コード（Shift_JIS／UTF-8）は自動で判定されます。列の名前が違っていても、取り込みの途中でステータス列などを選んで対応づけられます。ステータス列は必須です。

Freeプランの始め方を教えてください

メールアドレスとパスワードを設定し、利用規約に同意のうえ、届いた確認メールのリンクを開くと登録が完了します。クレジットカードは不要です。Freeプランは求人1件・1席で、A/B/C判定の基準やスカウト文の型など基本機能をお試しいただけます。
